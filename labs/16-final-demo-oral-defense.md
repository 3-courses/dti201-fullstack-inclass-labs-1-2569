## Oral defense ตัวอย่าง

- เปิด component ที่แสดง book card แล้วอธิบาย props
- endpoint ใดสร้าง reading note
- validation อยู่ frontend หรือ backend
- database field ใด sensitive
- ถ้า API ล่ม UI แสดงอะไร
- ถ้าต้องเพิ่ม search จะเพิ่มที่ชั้นไหน
- prompt ใดของคุณปรับดีขึ้นมากที่สุด
- ReasoningTrace ใดแสดงว่าคุณตัดสินใจจาก evidence
