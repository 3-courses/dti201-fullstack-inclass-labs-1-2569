# Lab 08 — Midterm Practical แบบ AI-off

## เป้าหมาย

กลางภาคใช้ตรวจว่าทุกคนทำพื้นฐานเองได้โดยไม่ต้องพึ่ง AI:

- HTML semantic structure
- CSS responsive layout
- JavaScript/React form
- validation
- loading/error/empty state
- อ่าน error message
- อธิบายงานตัวเอง

## รูปแบบฝึก

ให้ starter project ขนาดเล็ก แล้วทำภายในเวลาที่กำหนด:

1. เพิ่ม field `readingStatus`
2. validate ว่าต้องเลือกสถานะ
3. แสดง badge ตามสถานะ
4. เพิ่ม empty state เมื่อ filter แล้วไม่เจอหนังสือ
5. เขียนคำอธิบายสั้น ๆ ว่าตรวจอย่างไร

## ห้ามใช้

- AI chat
- code generator
- copy code จากเพื่อน

## ใช้ได้

- notes ของตัวเอง
- MDN/React docs ตามที่ผู้สอนกำหนด
- DevTools
- terminal

## Evidence checklist

- code ที่แก้
- screenshot ก่อน/หลัง
- test case 3 กรณี
- คำอธิบาย 5-8 บรรทัด

## คำถาม oral checkpoint

- field ใหม่อยู่ใน type ใด
- validation อยู่ตรงไหน
- filter ทำงานอย่างไร
- ถ้า API ส่งข้อมูลว่าง UI แสดงอะไร
